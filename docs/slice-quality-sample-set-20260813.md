## 核验协议

1. 先由程序给出通过质量闸门的 trim；通常优先约 15–60 秒，但不把时长作为硬阈值。没有可靠 trim 时只给出上表的时间摘要，禁止把约 240 秒候选交给人工观看。
2. 观看时记录 `human_decision`、`human_reason_codes` 和一句 `human_notes`。至少检查 `standalone`、`hook`、`arc`、`payoff`、`abrupt_start`、`abrupt_end`、`no_payoff`、`danmaku_noise`、`wrong_focus` 和 `ordinary_goodbye`。
3. `pending` 不是质量结论。未完成独立核验前，不修改 MiMo 提示词、弹幕阈值或质量分阈值。
4. 本轮样本只用于质量复盘；不生成生产 pending，不进入投稿接口，也不加入上传队列。
